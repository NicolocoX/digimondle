## Digimondle

Digimondle es un juego web inspirado en Wordle y tematizado en el universo de Digimon. Este proyecto personal fue desarrollado para poner en práctica y profundizar mis conocimientos de React, JavaScript y CSS.

Durante su desarrollo, exploré herramientas y patrones de React que permiten optimizar el renderizado, mejorar la organización del código y facilitar su mantenibilidad. Además, tuve en consideración la accesibilidad durante el diseño y la implementación de la interfaz.

## La aplicación

El objetivo del juego es encontrar al Digimon secreto mediante pistas que se obtienen con cada intento. Para ello, el jugador selecciona Digimon a través de un buscador y recibe información sobre sus características, las cuales se presentan en casillas de colores que indican su nivel de coincidencia con las del Digimon objetivo.

La interfaz también cuenta con controles para reiniciar la partida, rendirse y cambiar entre los temas claro y oscuro.
